btcutil-js — examples

Live pages built on the modules of btcutil-js, the Bitcoin utility library for JavaScript/TypeScript via WebAssembly.

  • BIP-322 message signing & verification

    Sign and verify generic Bitcoin messages (simple and full BIP-322, plus legacy) — built on the bip322 module.

    Source: cryptography-toolkit/pages/bip322

  • PSBT editor

    Inspect, edit and finalize Partially Signed Bitcoin Transactions (BIP-174) — built on the psbt module.

    Source: cryptography-toolkit/pages/psbt-editor

  • Watch-only wallet (compact filters over HTTP)

    A browser-only watch-only wallet: validates block headers, verifies and matches BIP-158 compact filters locally in WASM, and fetches chain data from a user-configurable block-dn server — built on the neutrino, descriptors and txscript modules.

    Source: btcutil-js/examples/neutrino
